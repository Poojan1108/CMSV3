ResolveX — Our Project Report

Hey there! This is our project presentation for ResolveX, a premium platform we are building to make lodging and resolving complaints easy and transparent.

Current Status: We finished the entire landing page and the interactive mock login system!

Slide 02

Why are we building this?

  • The Problem: Existing portals are super outdated. Users get frustrated because complaints get lost and nobody knows who is working on them.
  • Our Solution: We created a workflow where complaints are structured, tracked in real-time, and routed to the correct department automatically.
Slide 03

What we used for the Frontend

⚡ React 19 & Vite 8

We chose React for building reusable UI components and Vite to bundle the app super fast during development.

🎨 Custom Vanilla CSS

We designed the dark mode and glassmorphism cards entirely in raw CSS to avoid bulky UI frameworks like Tailwind.

✨ Lenis Smooth Scroll

We added Lenis scroll physics so that scrolling through sections feels incredibly smooth and premium.

🔐 Interactive Auth Portal

We coded mock Login/Signup screens so users can see how the client-side authentication flow looks.

Slide 04

What we decided for the Backend

🔒 Firebase Auth

We decided to use Firebase to handle user signups, logins, and secure token management out-of-the-box.

🗄️ Supabase (PostgreSQL)

We chose Supabase to store our relational data (complaints, statuses, and profiles) and to leverage its real-time database sync.

⚙️ Custom API Layer

We will build a custom backend service to coordinate database queries, handle file uploads, and trigger alerts.

🤖 AI Auto-Routing

We want to add a backend script that reads complaint descriptions and auto-assigns them to the correct department.

Slide 05

Backend options we are considering

Option A: Node.js (Express/NestJS)

Our Recommendation: Lets us use JavaScript/TypeScript on both frontend and backend. We also get access to massive libraries and SDKs.

Option B: Python (FastAPI)

AI Friendly: Great if we want to write native machine learning classifiers to categorize complaint text automatically.
